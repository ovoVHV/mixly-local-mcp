# MAX30102 WASM blocks for Mixly 4

This plugin injects the SparkFun MAX3010x driver and Maxim PBA heart-rate
algorithm into Mixly 4's browser WASM `sketchFiles`. It does not depend on a
traditional Arduino `libraries/` installation.

Upstream: SparkFun MAX3010x Sensor Library 1.1.2, commit
`72d5308df500ae1a64cc9d63e950c68c96dc78d5`.

The sensor and algorithm are suitable for learning and prototyping, not
medical diagnosis.
